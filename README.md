### 🚀 O mnie / About Me

> *"Kombinacja wydajności Rust, architektury systemów rozproszonych i pasji do tworzenia silników gier."*

- 🦀 **Rust & Systems Programming**: Architektura niskopoziomowa, bezpieczeństwo pamięci, asynchroniczność oraz optymalizacja wydajności w **Rust**.
- 🎮 **Minecraft Engine & Open Source**:
  - **[Horizon](https://github.com/horizon-rust/horizon)**: Kontrybucje do natywnego silnika Minecraft: Java Edition napisanego w czystym Rust (wgpu, Metal, system renderowania `CustomHeadLayer`, podsystem audio).
  - **[RealWorldMC](https://github.com/Teddy563/realworldmc)**: Rozwój moda odwzorowującego Ziemię 1:1 (klimat WGS84, proceduralne pejzaże dźwiękowe, interaktywna mapa świata).
- ⚡ **Grafika & Renderowanie**: Praca z **WebGPU (wgpu)**, **Metal** oraz potokami renderowania 3D.
- 🛠️ **DevOps & Automatyzacja**: Testy parzystości (differential parity testing), CI/CD, konteneryzacja w **Dockerze** i środowiska **Linux / macOS**.
